# 💰 Cotizador de Servicios Web + Mini-Apps

Este repositorio contiene un **módulo interactivo** diseñado para ser integrado en un portfolio profesional. Incluye herramientas de conversión y fidelización de clientes.

## 🚀 Funcionalidades Principales
- **Cotizador Dinámico:** Algoritmo en JavaScript que calcula presupuestos personalizados según tipo de proyecto, cantidad de páginas y urgencia.
- **Integración con WhatsApp:** Envío automático del presupuesto detallado al chat del profesional.
- **Crypto Tracker:** Widget que consume la API de CoinGecko para mostrar precios de BTC/ETH en tiempo real.
- **Interactividad:** Incluye una To-Do List y un juego de lógica (Skull Tap) para demostrar manejo del DOM.

## 🛠️ Instalación e Integración
1. Clonar el repositorio.
2. Copiar los bloques de la sección `#quote` del HTML en tu proyecto principal.
3. Importar los estilos del archivo `style.css` y la lógica de `script.js`.

## ⚙️ Tecnologías
- HTML5 / CSS3 (Flexbox & Grid)
- JavaScript Vanilla (Async/Await para la API)
- FontAwesome para la iconografía
